# Pivot to agentic-commerce conformance

The initial failed-payment recovery concept overlapped Razorpay's built-in retry behavior and several existing AI recovery products. We chose Vowgate under Track 1 instead: an agent-readable merchant flow whose differentiator is adversarial proof that every Razorpay test transaction remains inside a customer-approved purchase mandate. This trades the simpler recovery demo for a more technically ambitious but more distinctive end-to-end commerce and safety demonstration.
